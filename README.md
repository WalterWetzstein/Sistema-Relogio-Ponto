# Sistema Relógio Ponto

Sistema web para importar a planilha de registro de presença e calcular o pagamento dos funcionários.

## Funcionalidades

- Cálculo por hora trabalhada ou por diária.
- Identificação automática do período e das datas da planilha.
- Um único adicional de hora extra para sábados, domingos e feriados.
- Feriados nacionais e feriados religiosos municipais de Curitiba.
- Resumo de funcionários, dias, horas e valor total.
- Aviso de jornadas com batidas incompletas.

O processamento é feito no próprio navegador; a planilha não é enviada para um servidor.
